## ۳. دستورالعمل اجرایی تسک R13: رفع خطاهای ساختار و لایوت مودال‌ها

این تسک بر روی ساختار چیدمان و ثبات دسترسی در نمای موبایل اسکرول‌پذیر متمرکز است.

### گام ۳.۱: لود و ایمپورت بحرانی `Page` در ChatView
دلیل: استفاده از شرط‌ها یا روت‌خوان‌های Page در کامپوننت چت بدون ایمپورت مستقیم ایجاد خطای زمان اجرا می‌کند.
- **مسیر فایل:** `/features/chat/ChatView.tsx`
- **اقدام:** خط تعریف ایمپورت را ممیزی کرده و مطمئن شوید enum یا آبجکت `Page` مستقیماً از فایل ماژول ریشه `types` ایمپورت شده است:
  ```typescript
  // قبل:
  import { ChatMessage, ChatMode, Citation, Task, Note, ActionResult, Project, ChatSession, ExtractionProposal } from '../../types';
  // بعد:
  import { ChatMessage, ChatMode, Citation, Task, Note, ActionResult, Project, ChatSession, ExtractionProposal, Page } from '../../types';
  ```

### گام ۳.۲: حذف کامل کلاس فیک `dir-rtl` و جایگزینی با ویژگی واقعی `dir="rtl"`
کلاس `dir-rtl` در استایل‌های تلویند نامعتبر است و المان‌ها را راست‌چین نمی‌کند.
- **اقدام:** در تمام پکیج فرانت (خصوصاً فایلهای زیر) جستجو کنید و کلاس `dir-rtl` را از بخش `className` حذف کنید. به جای آن، ویژگی `dir="rtl"` را مستقیماً به المنت والد JSX اضافه کنید:
  - `features/tasks/components/TaskEditorModal.tsx`
  - `features/habits/components/HabitEditorModal.tsx`
  - `features/projects/components/ProjectDetailsModal.tsx`
  - یا هر بخش دیگر مانند داک لایوت‌ها.

### گام ۳.۳: اعمال قانون `min-h-0` و `h-[100dvh]` به اسکرول داخلی مودال‌ها
برای جلوگیری از پنهان شدن دکمه‌های داک تهتانی (مثل ثبت و کنسل) پشت کیبورد مجازی موبایل داک شده.
- **اقدام:** هر مودال دارای فیلد ورودی یا تریگر اسکرول در موبایل باید کانتینر اصلی اسکرول‌پذیر آن دارای کلاس تلویند `min-h-0` باشد تا قابلیت جمع شدن برای کیبورد داینامیک وب را حفظ کند.
- فایلهای مشمول فیکس:
  - `features/tasks/components/TaskEditorModal.tsx`
  - `features/habits/components/HabitEditorModal.tsx`
  - `features/notes/components/NoteEditorModal.tsx`
  - `features/projects/components/ProjectDetailsModal.tsx`

### گام ۳.۴: تراز اتمیک سلسله مراتب Z-Index طبق استاندارد پروژه
برای همپوشانی روان مودال‌ها روی یکدیگر بدون تریدآف تعاملی.
- **اقدام:** بازنویسی دقیق استایل‌های والد پوشاننده (Overlay & Backdrop) مودال‌ها طبق مقادیر زیر:
  1. **مودال ویرایش تسک / کارها (`TaskEditorModal.tsx`):** زبانه `z-index` والد بیرونی باید به `z-[60]` ارتقا یابد.
  2. **مودال عادت‌ها (`HabitEditorModal.tsx`):** کلاینت والد بیرونی باید به `z-[60]` مجهز شود.
  3. **مودال یادداشت‌ها (`NoteEditorModal.tsx`):** باید مقدار `z-[60]` را حفظ کند.
  4. **مودال جزئیات پروژه (`ProjectDetailsModal.tsx`):** از آنجا که می‌تواند از داخل کارت‌های با اولویت بالا باز شود یا مودال کارها روی آن لود شود، مقدار والد آن باید دقیقاً `z-[70]` تنظیم شود.
  5. **کشوی کشویی چت دیروز (`ChatHistoryDrawer.tsx`):** مقدار لایه پوشاننده آن بر روی دسکتاپ و موبایل باید `z-[60]` تنظیم شود.

### گام ۴.۱: حذف دسکتاپ کوئری‌ها در گریدهای پروژه‌ها
- **مسیر فایل:** `/features/projects/ProjectsView.tsx`
- **اقدام:** کانتینر نمایش کارت‌های پروژه را به جای گرید چندستونه دسکتاپ به یک گرید تک‌ستونه تمیز سازگار با صفحه لمسی موبایل تبدیل کنید:
  ```jsx
  // قبل:
  <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  // بعد:
  <div className="grid grid-cols-1 gap-4">
  ```

### گام ۴.۲: بهینه‌سازی فاصله‌های تعاملی و ابعاد در ProjectCard
- **مسیر فایل:** `/features/projects/components/ProjectCard.tsx`
- **اقدام:**
  - پدینگ کارت را از `p-5` به `p-4` تغییر دهید تا فشرده‌تر و برای اسکرین موبایل‌های SE مناسب شود.
  - فواصل داخلی متن‌ها را تصحیح کنید تا با گپ کلی سازگار باشند.

### گام ۴.۳: برآورده‌سازی استانداردهای تداخل Bottom Navigation
تمام صفحاتی که اسکرول آزاد دارند باید در پایین صفحه فضای کافی داشته باشند تا دکمه‌های پایانی توسط منوی چسبان پایینی (Bottom Navigation) خورده یا کاور نشوند.
- **اقدام:**
  - صفحات زیر را چک کنید و اطمینان یابید کانتینر اصلی اسکرول آن‌ها پدینگ پورت به صورت `pb-24` یا `pb-32` دارد.
  - **پکیج هدف:** به طور خاص صفحه‌ی اشتراک‌ها `/features/billing/pages/SubscriptionPage.tsx` را بررسی کرده و اگر در کانتینر پایانی فاقد پدینگ پایین مناسب بود، کلاس `pb-28` را اعمال کنید.
