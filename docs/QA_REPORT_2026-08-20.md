### فاز ۵: recurrence سرورمحور

**وضعیت:** ✅ کامل (server-side)

**جدول‌ها:**
- `task_recurrence_series` — rule canonical، timezone، version
- `task_recurrence_exceptions` — skip/override/cancel

**RPCها:**
- `complete_recurring_task_v2` — complete + spawn next در یک transaction
- `skip_recurring_occurrence_v2` — skip بدون completion
- `edit_recurring_series_v2` — scope current/future
- `stop_recurring_series_v2` — keepCurrent/cancel

**محافظت‌ها:**
- version conflict detection
- idempotent replay
- Jalali/Tehran timezone-aware
- completed history never rewritten
- series owner mismatch protection

**شواهد:** smoke زنده: complete→spawn، skip→exception، edit_current→anchor only، edit_future→rule version bump، stop→series closed

**باگ‌های کشف‌شده:**
1. `stop` ردیف‌های بدون series id را رد می‌کرد → رفع شد
2. `edit_future` anchor تکمیل‌شده را بازنویسی می‌کرد → رفع شد

### فاز ۶: Reminder outbox

**وضعیت:** ✅ کامل (server-side)

**جدول‌ها:**
- `notification_messages` — message_id منطقی، occurrence key یکتا
- `notification_deliveries` — per endpoint/attempt
- `notification_dead_letters`

**RPCها:**
- `enqueue_notification_message` — idempotent enqueue
- `claim_notification_messages` — `FOR UPDATE SKIP LOCKED` با lease
- `record_notification_delivery` — per endpoint
- `finalize_notification_message` — sent/partial/retry/dead
- `supersede_notification_message` — snooze/reschedule
- `mark_notification_message_read`

**محافظت‌ها:**
- duplicate enqueue → same message_id, one row
- two workers → disjoint batches
- worker crash → lease reclaim
- partial delivery → no retry for succeeded endpoints
- stale messages → cancelled before delivery
- double-send prevention: dispatcher checks flag before materializing

**شواهد:** SQL probes داخل rolled-back transactions: all invariants verified

**شواهد:** ۲۲ سناریو + targeted tests

### فاز ۸: Memory V2

**وضعیت:** ✅ کامل (server-side + live retrieval)

**جدول‌ها:**
- `memory_documents` — source version/hash، embedding model/dimensions
- `memory_chunks` — content، span، embedding vector(768)
- `memory_jobs` — idempotent، lease، stale supersede
- `memory_backfill_runs` — resumable cursor

**RPCها:**
- `enqueue_memory_job` — idempotent with stale supersede
- `claim_memory_jobs` — `FOR UPDATE SKIP LOCKED`
- `finalize_memory_job` — succeeded/stale/failed/dead
- `upsert_memory_document` — version guard، chunk replace
- `delete_memory_document` — cascade
- `search_memory_v2` — 4-signal RRF: dense KNN + FTS + trigram + exact title
- `backfill_memory_documents` — resumable cursor

**Triggers:**
- `memory_index_tasks/notes/projects` — enqueue on INSERT/UPDATE/DELETE

**Worker:**
- `memory-indexer` — claims jobs، re-reads source، verifies version/hash، embeds via `gemini-embedding-2`

**محافظت‌ها:**
- stale write rejected when source version advanced
- duplicate job collapses to one row
- two workers claim disjoint batches
- type/time/project filters inside SQL before limit
- cross-user isolation verified

**شواهد:** ۳ پروژه واقعی indexed، ۳ chunks با embedding 768d، retrieval زنده: exact title wins، lexical hit، type filter excludes، other user sees nothing

**باگ کشف‌شده:** `projects.project_id` column error در indexer → رفع شد

## ۳. باگ‌های کشف‌شده و رفع‌شده

| # | باگ | علت | رفع |
|---|---|---|---|
| ۱ | Undo روی `tags=null` شکست می‌خورد | JSON null scalar بود، `jsonb_array_elements_text` خطا می‌داد | `jsonb_typeof` check اضافه شد |
| ۲ | `UPDATE_TASK_CHECKLIST` → `500` | validator `params.checklist` می‌خواست، مدل `params.updates.checklist` تولید می‌کرد | قرارداد به `updates.checklist` تغییر کرد |
| ۳ | override روی flag غیرفعال کار نمی‌کرد | `enabled=false` بدون توجه به override، `inactive` برمی‌گرداند | منطق اصلاح شد: `stage=off` kill switch مطلق، بقیه override می‌پذیرند |
| ۴ | replay درخواست تمام‌شده مدل را دوباره صدا می‌زد | `startAiRequest` روی reservation succeeded خطا می‌داد | `409 idempotent_replay` بدون re-call مدل |
| ۵ | worker بردارسازی نسخهٔ کاربر را باطل می‌کرد | trigger `embedding` write را version bump می‌کرد | trigger فقط تغییرات معنادار را می‌شمارد |
| ۶ | `on conflict` روی index پارشیال شکست می‌خورد | partial index قابل match نبود | read-then-insert با قفل ردیف |
| ۷ | `stop` ردیف بدون series id را رد می‌کرد | legacy rows series id نداشتند | lazy series creation اضافه شد |
| ۸ | `edit_future` anchor تکمیل‌شده را بازنویسی می‌کرد | completed history rewrite می‌شد | anchor فقط وقتی open باشد rewrite می‌شود |
| ۹ | `projects.project_id` در indexer وجود نداشت | projects جدول parent ندارد | conditional column selection |
| ۱۰ | `focus_sessions` TRUNCATE برای `anon` | default ACL همه privilege را grant می‌کرد | revoke + explicit grant |
